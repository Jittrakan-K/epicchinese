# Epic Chinese · เรียนภาษาจีนจากศูนย์ถึง HSK 6

เว็บติวภาษาจีนสำหรับคนไทย ตั้งแต่ยังไม่รู้สักตัวไปจนถึง HSK 6 เป็น HTML5 ล้วน ไม่ต้องติดตั้งหรือ build อะไร เปิดบน GitHub Pages ได้ทันที

## มีอะไรบ้าง

- **แผนที่เส้นทาง** ภูเขาจากฐานถึงยอด HSK 6 บอกว่าตอนนี้อยู่ตรงไหน ผ่านอะไรมาแล้ว ทุกบทที่ผ่านจะได้ตราประทับสีแดง
- **ฐาน 4 ด่าน** วรรณยุกต์ พินอิน (ตารางเสียงพร้อมคำเทียบเสียงไทย) ขีดและลำดับการเขียน หมวดนำ
- **คำศัพท์ HSK 2.0 ครบ 4,991 คำ** แบ่งเป็น 165 บท ทุกคำมีความหมายภาษาไทยและภาษาอังกฤษ
- **แต่ละบท** มีบัตรคำพร้อมเสียงอ่าน ดูลำดับขีด ฝึกเขียนบนตาราง 米字格 และแบบทดสอบ 4 แบบ (ความหมาย ตัวอักษร ฟังเสียง พินอิน) ผ่าน 80% จึงไปบทต่อไป
- **สอบวัดระดับ** ทุกระดับ สอบผ่านแล้วข้ามทั้งระดับได้เลยสำหรับคนที่มีพื้นฐาน
- **ทบทวนแบบเว้นระยะ** คำที่เรียนแล้วจะกลับมาตามจังหวะความจำ (ลืม / จำได้ / ง่ายมาก)
- **ไวยากรณ์** 54 หัวข้อ แยกตามระดับ พร้อมตัวอย่างที่กดฟังได้
- **ฝึกฝน** รวมเกมและแบบฝึกเสริม เลือกได้ว่าจะฝึกจากคำที่เรียนแล้วหรือระดับไหน
  - จับคู่คำแข่งกับเวลา 3 รอบ
  - เรียงประโยคจากตัวอย่างไวยากรณ์
  - ฟังแล้วพิมพ์ (พินอินไม่ใส่วรรณยุกต์ก็ได้ หรือพิมพ์ตัวจีน)
  - พูดตาม ใช้ระบบฟังเสียงของเบราว์เซอร์ (Chrome / Edge) ตรวจการออกเสียง
  - คำที่ตอบผิดบ่อย และคำที่บันทึกไว้
  - วัดระดับ ไล่จาก HSK 1 ขึ้นไป แล้วข้ามไปเริ่มระดับที่เหมาะได้เลย
  - ฝึกเสียง ตารางพินอินทั้งหมด กฎการเปลี่ยนเสียง และเกมทายวรรณยุกต์
- **คำประจำวัน** และปุ่ม **บันทึกคำ** ที่บัตรคำ คลังคำ และหน้าคำประจำวัน
- **คลังคำ** ค้นหาด้วยตัวจีน พินอินไม่ใส่วรรณยุกต์ ไทย หรืออังกฤษ
- **สถิติ** วันต่อเนื่อง XP เป้าหมายรายวัน กราฟกิจกรรม ตราประทับความสำเร็จ 20 แบบ ส่งออก/นำเข้าความคืบหน้า ธีมสว่างและมืด
- ใช้งานออฟไลน์ได้ (PWA) และรองรับมือถือ

ความคืบหน้าทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์ ไม่ต้องสมัครสมาชิก

## เปิดบน GitHub Pages

1. ไปที่ **Settings → Pages** ของ repo นี้
2. ตรง **Build and deployment** เลือก Source เป็น **Deploy from a branch**
3. เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ เว็บจะอยู่ที่ `https://jittrakan-k.github.io/epicchinese/`

## รันในเครื่อง

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

เปิด `index.html` ตรงๆ ก็ได้ แต่ข้อมูลลำดับขีดจะโหลดจาก CDN แทนไฟล์ในเครื่อง

## เสียงอ่าน

ใช้ Web Speech API ของเบราว์เซอร์ ถ้าไม่มีเสียง ให้ติดตั้งเสียงภาษาจีน (zh-CN) ในเครื่อง
- Windows: Settings → Time & Language → Speech → Add voices → Chinese (Simplified)
- macOS / iOS: ส่วนใหญ่มีเสียง Tingting อยู่แล้ว
- Android: ติดตั้ง Speech Services by Google แล้วดาวน์โหลดภาษาจีน

## โครงสร้าง

```
index.html            หน้าเดียว (SPA ใช้ hash routing)
css/style.css         ดีไซน์ทั้งหมด
js/app.js             ตรรกะของแอป
js/data-words.js      คำศัพท์ HSK 1–6
js/data-content.js    วรรณยุกต์ พินอิน ขีด หมวดนำ ไวยากรณ์
js/icons.js           ไอคอน (Lucide)
vendor/               Hanzi Writer
data/strokes/         ข้อมูลลำดับขีดของอักษรทุกตัวที่ใช้ใน HSK
sw.js                 แคชสำหรับใช้งานออฟไลน์
tools/                ความหมายภาษาไทยและสคริปต์สร้างไฟล์คำศัพท์
```

อยากแก้ความหมายภาษาไทย ให้แก้ไฟล์ใน `tools/thai/*.tsv` (ตัวจีน, แท็บ, ความหมายไทย) แล้วรัน `python3 tools/build_words.py` เพื่อสร้าง `js/data-words.js` ใหม่ ถ้าแก้ไฟล์ JS อื่นแล้ว ให้เปลี่ยน `VERSION` ใน `sw.js` เพื่อให้เครื่องผู้ใช้โหลดไฟล์ใหม่
